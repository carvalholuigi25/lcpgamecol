ADMIN ONLY

How uploads are kept safe

  • Only administrators can upload, list, download, or delete files.
  • The file contents must match an allowed type; the name and browser-reported type are not trusted.
  • SVG, HTML, scripts, and other active content are refused.
  • Files are size-limited while they stream and stored under random names outside the public folders.
  • Downloads are sent as attachments with a locked-down content policy.
